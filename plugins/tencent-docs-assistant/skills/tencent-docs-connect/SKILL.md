# 腾讯文档连接

默认使用中文。本插件通过腾讯官方 MCP 提供能力，OAuth 用于授权，二者共同工作。

## 检查与连接

1. 先检查宿主已暴露的腾讯文档工具。已有工具时以 `get_user_info` 做最小只读验证，不创建文档、遍历全部文件或重复 OAuth。不要在回复暴露完整 user_id。
2. 没有工具时检查当前宿主的 MCP 连接状态。桌面端若有终端，可用 `codex mcp list --json` 检查已有配置；只检查服务器和认证状态，不读取或输出凭据文件。
3. 已配置 `tencent-docs` 时使用桌面设置中的 Authenticate，或 `codex mcp login tencent-docs --oauth-client-registration dcr`。尚无配置才使用 `codex mcp add tencent-docs --url https://docs.qq.com/openapi/mcp --oauth-client-registration dcr`。命令参数以本机 help 支持的版本为准，不覆盖已有不同账号的连接。
4. 用户在腾讯官方授权页完成登录、扫码和权限同意；不要求把密码、Token、验证码、Cookie 或授权码发到聊天中，不从 WorkBuddy 或其他应用复制登录凭据。
5. 授权后重新发现工具；当前聊天没加载新工具时提示重启桌面端或重新打开聊天，不替用户擅自新建聊天，不重复创建插件。工具出现后再用只读账号查询验证。
6. 区分已保存插件、已安装、已授权、工具已加载、只读调用成功和具体文档操作成功。工具数量可变化，账号查询成功也不代表所有文档均可读写。

桌面 MCP 登录凭据由本机宿主管理，不应打包上传。个人插件版本可保存到账号，但新设备可能仍需安装依赖并重新授权。网页端是否可用取决于该宿主的连接与 OAuth 支持，不能从桌面登录成功推定网页已连接，也不能声称本插件已成为平台注册应用。

## 错误处理

| 返回情况 | 处理 |
| --- | --- |
| 401、invalid_token、Token 失效、400006 | 通过宿主重新授权，成功前不继续写入 |
| 403 或权限不足 | 核对账号、文件权限和操作范围，不默认重登 |
| 400007 | 套餐不足，由用户自行决定，不代购 |
| 400008 | 服务报告积分不足，说明受影响操作，不代购 |
| 400016 | 类型不匹配，查询文件类型并切换对应工具 |
| 超时、限流、服务异常 | 只读可有限重试；写入结果不明先核实远端状态 |
| OAuth 注册或回调不兼容 | 记录不含凭据的错误，报告连接未完成，不改用不安全的凭据传递 |

官方地址、协议与参考资料见 [连接参考](references/connection.md)。
