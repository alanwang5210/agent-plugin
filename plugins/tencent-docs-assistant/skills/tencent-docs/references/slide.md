# 幻灯片 SLIDE

## 页面与形状

编辑前先 `slide_get_info` 获取页数、顺序和页面尺寸，再 `slide_get_page_info` 查询目标页的真实 shape ID、类型和位置。`page_index` 从 0 开始，用户口语中的第 1 页应映射到 0。大型演示文稿逐页或按任务范围读取，不获取全部页面详情。

`get_content` 可做只读摘要，不能作为幻灯片编辑上下文。使用当前宿主的 `slide_*` 工具，不套用 DOC 字符索引或智能文档 Block/MDX 编辑，也不自动安装官方独立的 slide-mcp、JSX 或本地凭据工具链。

## 内容和样式

- 修改文字先用 `slide_get_text` 取真实文本和区间；字符范围以其返回的 UTF-16 长度为准，包括可能的结尾回车。不能用屏幕字数、Unicode 码点数或表格摘要的文本长度代替。
- 表格用相应表格工具；row/col 从 0 开始，合并单元格定位左上角。仅修改样式时使用样式工具，不用覆盖整段文字达到格式变化。
- 追加备注用 `slide_append_notes_text`。修改已有备注先 `slide_get_notes_text`，在保留其他内容的基础上才用 `slide_set_notes_text`；set 会覆盖全部备注，空字符串会清空。
- 坐标、尺寸、颜色和批量限制看具体 schema；常见坐标单位是 pt，部分返回值也提供 EMU，不混用。页面索引、形状 ID 在插入、删除、移动后重新核对。
- 多个相同类型新增操作优先用实际提供的批量工具，仍检查结果。图片使用当前宿主支持的上传与插入方式，不复制其他应用凭据或擅自运行官方包的直连脚本。

## 撤销与验收

用户要求撤销某次 AI 编辑时，先 `slide_list_recent_ai_edits` 查询记录，根据操作和参数匹配真实 version，再 `slide_undo_ai_edit`。不能凭记忆填写版本，也不能把此接口当作对所有人工操作都适用的版本恢复。

写后重新读取目标页、文本或备注；可用预览时检查遮挡、溢出和图片显示。未获得渲染预览时只报告结构或文本已验证，不声称视觉验收通过。
